
# Blood Bank Management System

## Project Information
- **Project Number:** 78
- **Project Title:** Blood Bank Management System
- **Programming Language:** Python 3
- **Project Type:** Console-Based Application

## 1. Project Overview
The Blood Bank Management System is a Python application designed to manage blood donors, blood stock, blood issuance, and donor searching.

It provides a simple menu-driven interface that helps users perform basic blood bank operations.

## 2. Problem Statement
Managing donor details and blood stock manually can be difficult. This project provides a simple system to maintain donor records, check blood availability, issue blood, and search donors by blood group.

## 3. Objectives
- Add new blood donors.
- Issue blood according to availability.
- View available blood stock.
- Search donors by blood group.
- Store donor information in a text file.
- Validate user input.

## 4. Features
1. Add Donor
2. Issue Blood
3. View Blood Stock
4. Search Donors
5. Exit

## 5. Technologies Used
- Python 3
- Lists
- Dictionaries
- Conditional Statements
- Loops
- File Handling
- Input Validation

## 6. Project Files
- `blood_bank.py` – Main Python program.
- `donors.txt` – Stores donor information.
- `test_cases.md` – Test cases and expected outputs.
- `README.md` – Project documentation.
- `.gitignore` – Excludes unnecessary files from Git.

## 7. How to Run the Project
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the VS Code terminal using Terminal → New Terminal.
4. Run the following command:

```bash
python blood_bank.py
```

If needed on Windows, use:

```bash
py blood_bank.py
```

## 8. Testing
The project should be tested for:
- Adding a donor with valid details.
- Issuing blood when sufficient stock is available.
- Handling insufficient stock.
- Rejecting invalid blood groups.
- Searching donors by blood group.

Refer to `test_cases.md` for detailed test cases.

## 9. Expected Outcome
The system helps manage donor records and blood stock through a simple menu-driven Python application.
